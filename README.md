# QR-code-generator
An interactive QR code generator thar allows users to create QR codes instantly using HTML , CSS and JavaScript.

## Usage

1. Type or paste your text or link into the input box.
2. Your QR code appears instantly — download it as an image.
3. Print it or share it anywhere: posters, menus, business cards, payment pages.
## How it works

Type or paste any text or URL, and the app generates a QR code for it instantly in your browser using a QR library — no server, no uploads, your data never leaves the page. Download the generated code as an image and use it anywhere.
